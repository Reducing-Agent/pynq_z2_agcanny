Why This Is Hard

  • Fixed thresholds fail in the dark. A Canny threshold tuned at desk lighting collapses under low illumination: noise crosses it, real edges do not.
  • Fixed thresholds fail under noise too. Lowering them to keep dim edges floods the output with false edges.
  • Naïve HLS is slower than ARM. Our first version read the 3×3 window from DDR nine times per pixel and came out at 0.76× — slower than NumPy.
  • Green tools can still be wrong. Synthesis reported II=1 and zero warnings while the board measured 20.57 ms — 6.7× off the roof.

Noise-Aware Adaptive Threshold

PL measures per-pixel noise with an Immerkær operator and returns σ through an ap_return register; ARM converts it to Canny thresholds once per frame.

RuleResult
HIGH ≈ 7.56σsweet spot
3σtoo loose
10σedges lost
16σ (naïve)no edge survives
The 7.56 coefficient is not a guess: it folds in the 0.2734 attenuation of stage 1, because σ is measured before denoising while the Sobel magnitude is computed after it. Ignoring that factor gives 16σ and kills every true edge.

Where the 6.31× Came From

Root cause: the DDR write sat inside an if. A conditional write defeats AXI burst inference and degrades to one handshaked transfer per pixel.

Pathcyc/px
op 0 — unconditional write1.05
op 1–8 — write in if(x≥2)6.70
op 9–11 — write in if(y≥8&&x≥8)6.70
op 1–11 after fix1.06

Fix: results land in an on-chip output line buffer outr[2][MAX_W] (ping-pong by row parity), then DDR is written unconditionally and contiguously. Cost: 4 RAMB18.

Decisive counter-example. Our first hypothesis blamed the σ accumulator. It was wrong: op 9–11 have no σ accumulator at all, yet were exactly as slow. One counter-example beat a three-sample comparison that looked perfectly consistent.

Throughput is decoupled from operator complexity. Grayscale pass-through takes 3.222 ms; the full neighbourhood pipeline takes 3.258 ms — a 1% gap. Adding operators costs LUT, not time: the pipeline is memory-bound, not compute-bound.

Reproducible End to End

  • Command-line only. v++ -c → --impl → --package → Vivado Tcl — no GUI clicks, CI-ready.
  • Bitstream versioning by MD5. Every .bit for this device is exactly 4 045 771 bytes, so file size cannot tell versions apart.
  • Python A/B mirror before synthesis. 702 cases compared byte-for-byte before touching the bitstream, so boundary bugs never reach the board.
  • Reusable skill package. 17 documented failure cases, each with trigger, evidence and its boundary of validity.
