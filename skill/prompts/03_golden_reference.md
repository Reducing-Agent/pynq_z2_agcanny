# 提示词模板 03 · 生成黄金参考并对拍

## 适用场景

写好了 HLS 实现，需要一份**独立**的参考实现来验证功能正确性，
并且这份参考要能被评审当场跑通、结果可复核。

## 在本项目中的效果

产出 `filters.py`（numpy 整幅向量化实现），与 HLS 输出逐像素比对，
最大差值 0。支撑了 `validate_v8.py` 的 **180 组逐像素对拍**（5 图 × 12 模式 × 3 增益）
和 72 组 σ 回读比对，全部失败 0 组。这份参考也是评审能当场复跑的东西。

## 提示词模板

```
我要为下面这个 HLS 算子写一份黄金参考实现，用于验证硬件输出。

【HLS 源码或算法描述】
【定点格式：如 uint8 输入、Q8.8 增益、中间多少位】
【边界处理约定：图像外圈几圈恒 0？】
【我要支持的模式 / 参数组合：列出来】

请生成 Python（numpy 整幅向量化）参考实现，并遵守以下要求：

1. **必须独立于我的 HLS 实现来写**——不要照抄我的循环结构，
   用 numpy 的整幅运算。两份独立实现得到同一结果才有意义。

2. **逐位对齐定点行为**，这点最容易被忽略：
   - 每一级的移位 / 截断位置要和我的一致
   - 可分离卷积若分两级，两级**分别**截断，
     不能合并成一次移位（两者的截断位置不同，会随机差 1）
   - 饱和到 0~255 的位置也要一致

3. **边界行为必须写死并测试**：外圈恒 0 的话，最小支持尺寸是多少？
   写一个最小尺寸哨兵用例（我们的是 9×9，因为四级流水线让有效区缩了 4 圈）。

4. 同时生成一个对拍脚本：
   - 遍历所有模式 × 所有参数组合（不要只测默认档）
   - 输出**最大差值**和**失败组数**，不要只打印 PASS
   - 每组失败时打印第一个不匹配的位置和期望/实际值

5. 请一并指出：哪些地方我的两份实现**最可能对不上**？
   （例：除法用移位近似时的取整方向、负数右移的行为）
```

## 使用说明

- 第 2 点是踩过坑的：一维核 `[1,4,6,4,1]` 系数和是 **16 不是 256**，
  一次 `>>8` 和分两级各 `>>4` 结果不同。参考实现必须与硬件**逐位一致**。
- 第 4 点要求"遍历所有组合"很关键。我们最早只测默认档，
  结果漏掉了增益非 1.0 时的行为。
- 第 5 点让模型主动列出风险位，比事后 debug 快得多。

## 失效条件

- 若算子含**非确定性**行为（依赖未初始化内存、浮点累加顺序），
  对拍会随机失败，此类算子需先消除非确定性。
- 参考实现本身有歧义时（如边界语义未约定），必须先约定再写，
  否则"对不上"到底是参考错还是硬件错，无从判断。
